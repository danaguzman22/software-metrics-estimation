> - SP completados = suma de SP de historias en estado Completada.

Esta especificación toma el alcance de la Issue US-16. Los escenarios BDD están en `features/US-16.feature`; la implementación sigue el flujo TDD.

## 1. Objetivo y alcance

Permitir consultar las métricas de un Sprint y el porcentaje de historias completadas de un proyecto:

- Story Points planificados para un Sprint.
- Story Points completados para un Sprint.
- Velocidad promedio del proyecto, calculada a partir de sus Sprints cerrados.
- Porcentaje de historias completadas en el backlog del proyecto, incluido el caso de backlog vacío.

No se agregan columnas, migraciones ni cambios a la persistencia para estas métricas. Se reutilizan las consultas y datos establecidos por US-09.

## 2. Modelo y dependencias

- `domain.Sprint` incluye `SPPlanificados *int`, según US-09. El valor es `nil` mientras el Sprint está `domain.EstadoSprintActivo`; al cerrar el Sprint se guarda el total planificado.
- `RepositorioSprints.ListarPorProyecto(proyectoID string) ([]domain.Sprint, error)` devuelve los Sprints ordenados por número.
- `ServicioSprints.StoryPointsCompletados(proyectoID string, sprintNumero int) (int, error)` calcula los Story Points de las historias completadas asignadas al Sprint.
- `ServicioSprints.VelocidadSprint(proyectoID string, sprintNumero int) (int, error)` devuelve los Story Points completados del Sprint.
- `domain.PorcentajeCompletadas(total, completadas int) (float64, error)` calcula el porcentaje entre 0 y 100, redondeado a dos decimales; con cero historias devuelve 0 sin error.
- Al cerrar un Sprint, US-09 elimina las asignaciones de historias no completadas. Por eso el porcentaje de esta historia se calcula sobre todas las historias del backlog del proyecto, no solo sobre historias que aún están asignadas a un Sprint.

## 3. Consultas y orden de evaluación

Las consultas de métricas validan el proyecto antes de consultar sus datos. Si el proyecto no existe, devuelven `domain.ErrProyectoNoEncontrado`. Cuando la consulta identifica un Sprint, este debe existir en ese proyecto; de lo contrario, se devuelve `domain.ErrSprintNoEncontrado`.

| Consulta | Resultado |
|---|---|
| `StoryPointsPlanificados(proyectoID, sprintNumero)` | Sprint activo: suma en vivo de los Story Points de sus historias asignadas. Sprint cerrado: valor persistido en `SPPlanificados`. |
| `StoryPointsCompletados(proyectoID, sprintNumero)` | Suma de Story Points de historias con estado `domain.EstadoCompletada` asignadas a ese Sprint. |
| `VelocidadSprint(proyectoID, sprintNumero)` | Igual a los Story Points completados de ese Sprint. |
| `VelocidadPromedio(proyectoID)` | Promedio de `VelocidadSprint` para los Sprints cerrados del proyecto. |
| `PorcentajeHistoriasCompletadas(proyectoID)` | Porcentaje de historias completadas sobre el total de historias del backlog del proyecto. |

Los errores de repositorio que no sean errores de dominio conocidos se propagan mediante `envolverErrorRepositorio`. No se informa éxito con datos incompletos.

## 4. Comportamiento esperado y decisiones derivadas

| Situación | Resultado esperado |
|---|---|
| Sprint activo con historias asignadas | Los Story Points planificados se calculan en vivo. |
| Sprint cerrado con `SPPlanificados` guardado | Se devuelve el valor guardado al cerrar, aunque ya no se conserven todas las asignaciones. |
| Consulta de planificados para Sprint cerrado sin `SPPlanificados` | Devuelve error; no se sustituye el dato ausente por cero. |
| Sprint sin historias completadas | Los Story Points completados y la velocidad individual son 0. |
| Proyecto sin Sprints cerrados | `VelocidadPromedio` devuelve 0 y `nil`. |
| Proyecto con Sprints cerrados, alguno con velocidad 0 | Los Sprints cerrados con velocidad 0 participan en el promedio. |
| Backlog vacío | `PorcentajeHistoriasCompletadas` devuelve 0 y `nil`. |
| Backlog no vacío | El porcentaje se calcula sobre todas las historias del proyecto y se redondea a dos decimales, conforme a `domain.PorcentajeCompletadas`. |
| Error de repositorio no conocido | Se propaga envuelto con `%w`; no se informa éxito. |

Las siguientes decisiones completan aspectos no especificados en la Issue. Se implementan como derivadas y quedan sujetas a revisión de Dana:

| ID | Resolución |
|---|---|
| P1 | **DERIVADA (a revisar por Dana):** `VelocidadPromedio` devuelve `(float64, error)`, para representar promedios fraccionarios sin perder precisión. |
| P2 | **DERIVADA (a revisar por Dana):** no se redondea el promedio de velocidad; se conserva el valor `float64` calculado. El redondeo de presentación, si se requiere, queda a cargo de la interfaz. |
| P3 | **DERIVADA (a revisar por Dana):** todos los Sprints cerrados del proyecto integran el promedio, incluso aquellos con 0 Story Points completados. Los Sprints activos no participan. |
| P4 | **DERIVADA (a revisar por Dana):** `StoryPointsPlanificados` para un Sprint cerrado con `SPPlanificados == nil` produce un error explícito; no se lo interpreta como cero ni se calcula a partir de asignaciones que US-09 pudo borrar. |
| P5 | **DERIVADA (a revisar por Dana):** la consulta nueva se denomina `VelocidadPromedio(proyectoID string) (float64, error)` y el porcentaje se expone como `PorcentajeHistoriasCompletadas(proyectoID string) (float64, error)`. |
| P6 | **DECIDIDA por Victoria:** el porcentaje se calcula sobre todas las historias del backlog del proyecto, estén o no asignadas a un Sprint; US-09 elimina las relaciones de las historias no completadas al cerrar. |

## 5. Criterios de aceptación y reglas

| ID | Requisito |
|---|---|
| CA1 | Los Story Points planificados son la suma de las historias asignadas. En un Sprint activo se calculan en vivo; en uno cerrado se devuelve el valor guardado por US-09. |
| CA2 | Los Story Points completados son la suma de los Story Points de las historias en estado `domain.EstadoCompletada` asignadas al Sprint. |
| CA3 | La velocidad promedio es el promedio de Story Points completados de los Sprints cerrados del proyecto. |
| CA4 | Si no hay Sprints cerrados, la velocidad promedio es 0 y no se devuelve error. |
| CA5 | El porcentaje de historias completadas se calcula correctamente con cero historias y devuelve 0 sin error. |
| R1 | Se valida primero el proyecto; las consultas por Sprint validan luego que exista ese Sprint en el proyecto. |
| R2 | Solo los Sprints cerrados participan en la velocidad promedio. |
| R3 | No se agregan persistencia, columnas ni migraciones para estas métricas. |
| R4 | Se reutiliza `domain.PorcentajeCompletadas`, cuyo porcentaje está entre 0 y 100 y redondea a dos decimales. |
